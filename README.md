# Test_Arduino_StreamingDeck
Test only for streaming deck buttons and knobs.
The code is written in C++ to be used with Arduino IDE.
Meant to be used with Arduino Micro.

The purpose of this project is testing 10 buttons and 5 knobs that will be configured with the Pro Micro to then be used as a streaming deck for PC

# File: Streaming_deck_arduino_IDE
This is the C++ code used in the Arduino IDE to give the functions directly to buttons and knobs.
Works with macropad.ahk (AutoHotKey), the Open Source program Deej and config.yaml
